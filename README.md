Repositório de distribuição dos APKs e informações de atualização do jogo. O código-fonte do jogo e as chaves de assinatura são mantidos separadamente.

Versão de teste publicada: **0.1.3 (código 4)**.

[Baixar APK 0.1.3](https://github.com/LifeMinerRPG/LifeMinerRPG/releases/download/v0.1.3/mina-profunda-v0.1.3-teste.apk) · [Ver a release](https://github.com/LifeMinerRPG/LifeMinerRPG/releases/tag/v0.1.3)

## Instalação e atualizações

1. Baixe e instale o APK no Android. Se já tiver o jogo, instale sobre a versão anterior, sem desinstalar.
2. Esta primeira instalação da 0.1.3 ativa o endereço das atualizações.
3. No jogo, abra **Opções → Verificar atualização**. Na 0.1.3, deve informar que a versão já está atualizada enquanto não houver uma versão posterior publicada.
4. Quando houver nova versão publicada, o botão abre o download no navegador. O Android solicita confirmação para instalar.

Moedas do jogo são virtuais. Os anúncios permanecem em demonstração. Esta versão não faz mineração real de criptomoedas nem pagamentos.
